# Dev-Blog

Foobar is a Python library for dealing with word pluralization.

## Installation

Use the package manager [npm](https://docs.npmjs.com/) to install requirements.

```bash
npm install
```

## Dependencies
```bash
npm install mongoose
```
```bash
npm install ejs
```
```bash
npm install nodemon
```
```bash
npm install body-parser 
```
